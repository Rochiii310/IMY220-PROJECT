# Ezpost

A photo-sharing website built for IMY 220.

## About
Ezpost lets users share photos, create playlists, and connect with others through posts, likes, and comments.

## Tech Stack
- Frontend: React
- Backend: Node.js / Express
- Database: MongoDB
